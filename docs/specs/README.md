# specs/

This is where a **written spec goes before it's built** — the input to a
task, not a record of one. Drop a filled-in spec here, then hand it to an
agent to plan from and execute. If you're looking for a record of what's
already been done, that's `../task-history/` instead.

**`ai-section-spec.md`** is the example already in this folder: a real,
filled-in spec (its own "interview pattern" format, predating the common
`../task-history/TEMPLATE.md`) for the `/ai` section build. Left exactly
as it was written — see `../task-history/2026-09-ai-section.md` for the
record of what actually shipped from it.

This repo also has Spec Kit scaffolding (`.specify/`, driving the
`speckit-*` skills) for a feature described from scratch with no context
yet — see `../task-history/2026-09-ai-section.md` for when it was added.
`.specify/memory/constitution.md` has never been filled in.
